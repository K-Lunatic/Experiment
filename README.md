# Experiment · 실험 기록

아이디어를 시험한 과정과 결과를 남기는 공간입니다. 완성된 서비스는 [Foundation](https://github.com/K-Lunatic/Foundation)에서 소개합니다.

## 현재 상태

아직 등록된 실험은 없습니다. 실험을 올릴 때에는 아래 네 항목과 재현에 필요한 코드·조건을 함께 남깁니다.

- 질문: 무엇을 확인하려 했나?
- 시도: 어떤 조건에서 무엇을 바꿨나?
- 결과: 실제로 관찰한 것은 무엇인가?
- 다음: 제한과 다음에 확인할 것은 무엇인가?

측정하지 않은 성능 수치나 계획 중인 기능을 완료 결과로 기록하지 않습니다.
