작은 코드 조각, 성능 비교, AI 도구 실험, 하드웨어 프로토타입 등 무엇이든 자유롭게 올립니다.

## 🧪 Experiments

아직 등록된 실험이 없습니다. 새로운 시도를 시작할 때 이 목록에 링크를 추가합니다.

실험마다 거창한 문서는 필요 없습니다. 아래 정도만 남겨도 충분합니다.

```md
# 실험 이름

- 질문: 무엇을 확인하고 싶었나?
- 시도: 무엇을 어떻게 해봤나?
- 결과: 실제로 어떻게 되었나?
- 다음: 이어서 해볼 것은?
```
